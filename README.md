# 闻小新 · 写作、审核与校对助手

“闻小新”是面向新闻与新媒体内容的 Skill，也可按写作目的、读者和材料处理其他文本。它支持从参考文章提炼表达特点、根据事实材料写稿、审核事实与逻辑、校对文字、跨平台改编及修改后复审。闻新周报与校园资料仅在明确要求时作为可选参考。

## 下载与使用

下载 [完整技能包](wenxiaoxin-news-review.zip)，解压后将 `wenxiaoxin-news-review` 文件夹放入宿主配置的技能目录，保持内部文件结构。启用后可问：“闻小新，你是谁，能做什么？”也可直接提供选题、参考文章、事实材料或现有稿件。

完整规则、来源说明、合成示例及验证记录均在 ZIP 中。技能不会自行增加宿主权限；联网、附件读取和格式导出取决于实际运行环境。不会自动覆盖原稿或发布内容。未选择开源许可证；参考材料的归属与改编范围见包内 `SOURCES.md`。
