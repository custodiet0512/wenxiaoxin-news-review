# 复审规则

先确定旧稿、旧报告及新稿。缺旧报告时可以独立审校新稿，但不能声称追踪了历史意见；缺新稿时索要新版，不凭“我改好了”判定问题解决。

1. 按旧问题编号比对对应原句与新稿；段落移动时依内容定位，不仅比较旧段落号。
2. 标记“已解决”仅限改动消除了原问题，并且所需事实依据已经具备。只换措辞而核心事实未核，不算已解决。
3. 未改、改动不足、证据仍缺或删改造成信息缺失的记为“仍待处理”，说明现状。
4. 新问题记为“新增问题”，使用不与旧报告重复的编号。没有旧编号体系时保留用户原编号并另设新编号。
5. 检查修改是否引入新的因果、承诺、数字矛盾或标题与正文不符。

输出旧编号、状态、新位置、判断依据与下一步，并附必要的新稿修改。不要根据一次复审宣称用户长期进步。用户明确要求归档时可按 [归档规则](archive.md) 保存记录，不能宣称自动跨会话记忆。
