# 校园与闻新周报可选参考

## 依据与适用方式

本文件按用户明确的参考请求使用，不因稿件提到某个学校或媒体自动启用。条目是可选检查角度，不能作为固定机构要求；不适用的条目直接略过。事实准确、隐私和来源等通用要求继续适用，用户明确提供并要求遵循的现行规范按规范接入流程处理。

公开资料支持校园媒体和学生声音的定位；历史样本呈现多种表达方式；以下具体检查由本技能为校园编辑工作提出。它们不是已证实的现行栏目、内部审稿制度或固定版式。依据与检索局限见 [公开来源记录](campus-sources.md)。不把历史人员、地点、联系方式和流行语当当前模板。

## 校园事实

- 学校、学院、系、专业与学生组织分开核对；简称在首次出现或跨平台转载时应能辨认，不凭习惯替换正式名称。
- “级”与“届”分别核对入学与毕业口径；不以学制推算实际毕业年份，不将休学、转专业等情况想当然。
- 活动名称、届次、主办/承办/协办、奖项名称与等级须对照当次通知或名单；不要把院级写为校级、入围写为获奖。
- 地点应足以让目标读者找到：校区、楼宇、房间按需要核对。不知道校区时列为待确认，不自动填入历史地点。
- 人物职务、年级和机构名称按事件时间核对；历史身份不因现任名单不同而直接判错。
- 多份材料冲突时先判断适用时间、发布主体及有无明确更正；没有明确依据，不自动认为海报、正文或较新的截图更可靠。

## 按内容选择文风

| 场景 | 检查重点 | 应保留的表达 |
|---|---|---|
| 活动消息 | 实际发生了什么、学生如何参与、结果与新闻价值；避免只有嘉宾名单和流程 | 准确的事实叙述，不机械删除必要嘉宾信息 |
| 学术报道 | 发言、提交论文、论文集收录、期刊发表、检索收录各有依据；学术观点明确归属 | 必要术语，不能为了通俗而改变学者观点 |
| 招新/服务指南 | 面向谁、如何参与、截止时间、地点、费用和条件是否足够行动 | 亲切称呼、短句与适当幽默，不强制改成通知腔 |
| 人物采访 | 引语、经历、细节有材料支撑；主观感受与可核验事实分开 | 受访者口语、个人视角与个性，不把转述重写为原话 |
| 校园生活/随笔 | 事实性细节和隐私；区分文学表达与新闻断言 | 合理比喻、情绪和抒情，不强套消息导语 |
| 校园议题/评论 | 问题证据、影响范围、不同说法与回应状态 | 合理批评和作者立场，不以维护形象为由改成赞美 |

上述名称用于审校路由，不宣称是公众号现有栏目。不得仅因有“成功举办”“同学们”等词就机械删改，应结合信息价值和证据判断。

## 学生声音与采访

“同学们一致认为”“全校学生都支持”需要对应群体依据。只有一位受访者时，将观点归给这位受访者，不推断代表性；不凭少量采访计算支持率。

涉及争议时区分事实、指控、当事人说法与评论；材料未呈现回应不等于对方拒绝回应。可建议补充采访，不替记者联系、编写回应或因未回应自动压下事实报道。

## 公众号交付检查

- 对齐标题、摘要、正文、已提供海报和图注中的名称、日期、时间及地点；关注跨年、星期与日期不符、相对时间在转载后失效。
- 招新及服务信息按实际需要检查截止时间、对象、报名方式、费用；用户提供的原通知足够明确时不重复索要。
- 图片未提供、二维码无法解码或链接无法访问时明确未检，不声称已验证跳转成功。
- 图注检查人物、地点、时间、素材性质与出处；旧图不误标当次现场。
- 只核对提供的作者、摄影、编辑和审核署名，发现冲突时指出。不生成真实姓名、不自动套用历史署名、不虚构“三审三校已完成”。

## 隐私与助手身份

针对出现的学号、宿舍门牌、联系方式、健康经历及聊天截图检查公开必要性和可识别性；不默认“已发群聊”即允许公开。可建议局部遮挡或匿名，但不能承诺去掉姓名就完全不可识别。公开报名联系方式与私人号码区别处理，避免影响服务信息可用性。

“闻小新”是本技能助手名称。不得自称公众号现任客服、编辑部成员或获得官方背书，不代收新闻线索、不承诺联系老师、学生或编辑部。收到此类请求时说明自身可协助整理内容，实际联系须使用用户确认的渠道并另获授权。
