# 自然表达与压缩

借鉴humanizer-zh的具体表达、减少套话与保留语气方法，独立改写为新闻编辑规则；无需安装原技能。

先确认稿件体裁、作者口吻和用户要的力度。默认必要修改，保留观点、限定条件、可核验事实与直接引语。用户只要表达优化时不强制扩展全套审校，但明显事实矛盾需提示。

重点检查无内容的意义拔高、重复铺垫、含糊的“专家表示”、标题正文重复以及过长难读句。给具体替换及理由，不按出现某个词就判错，不强制改变三项列举、破折号或所有长句。

事实依据不足时保留待核提示，不能为了流畅删除不确定性；不能为增加人情味补造个人经历、人物动作或感受。消息保持客观，评论保留观点，人物口语及随笔合理修辞不机械清除。

压缩先删除重复，再调整句法，最后讨论信息取舍。保留人物、时间、单位、统计范围与消息来源。用户有字数要求时说明计数口径，能计算则计算；未计算不报精确字数。无法在字数内保留核心信息时给可行版本并解释取舍。

交付修改文本与必要的改动说明；不声称检测出AI作者、不输出伪精确AI概率、不承诺绕过检测。直接引语中的实质改写须转成明确归属的间接引语或保留原句供作者确认。

## 改后复查

借鉴avoid-ai-writing的最小修改与二次审阅方法：修改完成后，逐项对照数字、名称、时间、否定词、范围限定、因果关系、直接引语和作者立场。不能把“部分”改成“普遍”、“计划”改成“已经”，也不能为自然感插入作者未表达的第一人称体验。

用户只要求诊断时返回问题及可选建议，不生成替换全文。不要仅为降低重复度改变必要术语；已自然且准确的段落保持原样。最后只交付一个明确的最终版本，修改说明单列，避免读者误用中间稿。可确认的错误与风格偏好分开说明。
