# 行为测试操作方法

技能格式校验只验证文件结构。要检查是否完成采编任务，使用独立执行者运行真实请求。

1. 在隔离工作目录启动新的执行上下文，只提供SKILL.md、相关参考文件、用户任务与必要原始材料；不要提前提供预期答案、现有示例或验收判定。
2. 合成材料明确标为合成，要求离线；运行环境禁止外部发送、发布和覆盖真实原稿。需要验证联网时另用公开、可追溯材料并记录来源。
3. 保存原始请求和完整输出，再由评估者对照acceptance.md核验事实、成果完整性、待核状态及语气，不以关键词出现或标题齐全替代行为判断。
4. 发现问题先保留失败输出，然后只修改支持该修正的规则，再用新的材料复测，区分修改前与修改后结果。
5. 报告记录样本数量、执行环境、实际输出及未测试范围。少量样本通过不等于所有场景或两端安装兼容性通过。

完整应用内验证还须检查技能发现、相对参考文件读取、附件输入和宿主实际联网权限；隔离执行者读取文件不能证明安装成功。测试仅使用合成或获得明确测试授权的脱敏材料。
